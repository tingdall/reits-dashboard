# 机构间REITs数据看板（REITs Dashboard）

> 上交所 + 深交所「持有型不动产」（机构间REIT / 持有型不动产ABS）项目数据的单文件 HTML 看板。

## 项目简介

将沪深两所债券平台公开发布的「持有型不动产」资产支持专项计划项目数据（当前 105 条），整理为一个**零依赖、免安装**的单文件 HTML 看板：打开即看，支持筛选、排序、图表、标记、导出，并可一键更新数据。

数据来源均为交易所官网**公开信息**（上交所债券项目信息平台 / 深交所固定收益信息平台），本仓库仅做数据整理与可视化，不含任何非公开内容。

## 特性

- **沪深双所融合**：统一数据模型，顶部 Tab 一键切换单所/合并，交易所徽章区分来源
- **项目智能分类**：经营权类（市政生态/交通设施/能源）+ 产权类（产业园/租赁住房/物流仓储/消费/数据中心/办公/综合业态/文旅类），支持点击单元格手动修正并持久化
- **多维度筛选**：关键字、交易所、项目类型、二级分类、状态、管理人、金额、日期等 11 个维度
- **图表概览**：状态分布环形图、计划管理人 TOP10、近 12 月受理趋势（原生 SVG，无图表库）
- **标记跟踪**：重点关注/已审核/待跟进 + 自定义标签，localStorage 双写持久化
- **双系统一键更新**（Mac / Windows 免装 Python）：
  - Mac：下载「更新数据.command」双击运行
  - Windows：下载「更新数据.bat」双击运行
  - 工具自动抓取两所最新数据 → 继承/自动分类 → 生成快照并**回写 HTML 内嵌数据**（单文件始终最新）
  - 手机/免脚本场景：导入快照文件（`reits_snapshot.js`）即可加载最新数据
- **增量更新**：已有项目分类字段自动继承，只处理新增变化，避免重复计算与覆盖人工修正

## 快速开始

```bash
# 1. 查看数据（浏览器直接打开，无需任何环境）
open 机构间REITs数据看板_v5分类版.html

# 2. 更新数据（Python 3，仅标准库；或直接用页面内下载的 Mac/Windows 工具）
python reits_update.py

# 3. 重新构建正式 HTML（改过模板/数据后）
python build_reits.py
```

## 目录结构

```
机构间REITs数据看板_v5分类版.html  # 主线看板（单文件自包含：数据+更新工具）
机构间REITs数据看板_正式版.html     # 基础正式版
reits_update.py                    # 双所数据抓取脚本（含增量分类逻辑）
更新数据.bat                       # Windows 双击入口
build_reits.py                     # 模板→HTML 生成脚本
reits_snapshot.js                  # 数据快照（页面启动优先加载）
cls_seed.json                      # 项目分类基线（增量更新的基础）
更新流程规范.md                    # 增量更新策略规范
AGENTS.md                          # 项目规则文件
```

## 可扩展性

本仓库的抓取架构（上交所 `ZQ_XMLB` / 深交所 `ShowReport` 接口 + Referer 处理 + 快照机制）与数据模型（`{id, num, name, mgr, writer, amt, status, up, acc, origin, ex, ptype, psub}`）是通用的，**可平滑扩展到公募REITs** 等其他资产类型的抓取（换关键词/接口参数即可）。
