数据来源：上海证券交易所债券项目信息平台 + 深圳证券交易所固定收益信息平台 · 持有型不动产（机构间REIT）项目 上交所搜索「持有型不动产」 ｜ 深交所项目进度信息 ｜ 抓取接口 reits_update.py（上交所 query.sse.com.cn + 深交所 bond.szse.cn） ｜ 标记数据保存在本地浏览器（localStorage 双备份）。
数据更新：两所接口均强制校验 Referer，浏览器无法直连。点击顶部「⟳ 数据更新」按钮，从本 HTML 内嵌下载 reits_update.py 与 更新数据.bat 到同文件夹，双击 bat 一键抓取两所最新数据，刷新本页即完成更新（无需另发工具文件）。
操作说明：
  • 重置视图（顶部按钮）：清除全部筛选条件、恢复默认排序（更新日期降序）并显示全部项目；不会清除标记标签（重点跟踪状态保留）。
  • 清除全部（筛选面板右上角）：仅清除筛选条件，排序方式保持不变。
  • 交易所：顶部 Tab「全部 / 上交所 / 深交所」与左侧筛选面板的「交易所」多选联动，可一键查看单所或合并数据；每行有交易所徽章（上交所橙 / 深交所蓝）便于区分来源。
  • 筛选：左侧面板支持关键字搜索、交易所、标记状态、项目状态、原始权益人、计划管理人、承销商多选（下拉仅列出实际存在的选项），以及拟发行金额区间、受理/更新日期区间；多条件可叠加。
  • 排序：点击表头（债券名称、原始权益人、金额、日期等）即可切换升/降序，金额与日期默认降序。
  • 标记：点击行尾「标记」按钮，或在任意数据行上右键，可打上「重点关注 / 已审核 / 待跟进」或自定义标签；标记随浏览器本地保存（localStorage 双备份），刷新不丢失。
  • 图表：「计划管理人 TOP10」支持按金额/单量切换，「近12个月受理趋势」按受理日期统计、支持金额/单量切换。
  • 导出 CSV：顶部「导出 CSV」按钮将当前筛选结果导出为表格文件（含标记列）。
  • 数据更新：点击顶部「⟳ 数据更新」，从本 HTML 下载 更新数据.bat 与 reits_update.py 到同文件夹，双击 bat 抓取两所最新数据后刷新本页（详见上方「数据更新」说明）。

⟳ 数据更新工具

浏览器安全策略无法直连交易所接口（需校验 Referer），数据更新需在本地运行小脚本完成。本 HTML 已内嵌更新工具，无需另发文件。
  1. 点击下方按钮，将 更新数据.bat 与 reits_update.py 下载到本 HTML 同一文件夹
  2. 双击 更新数据.bat（自动抓取上交所+深交所最新项目数据）
  3. 刷新本页面，即加载最新数据
⚠ 若双击 bat 弹出「Internet 安全设置阻止打开」：浏览器下载的文件带 Mark of the Web 标记。
本 bat 已内置自动解除逻辑（运行即生效）；如仍未解除：右键 bat → 属性 → 勾选「解除锁定」→ 应用 → 确定。
