分享即用：本文件单 HTML 即开即用——数据已内嵌，把本文件发给任何人（电脑/手机），打开即可查看全部项目数据，无需其他文件。
数据更新：两所接口均强制校验 Referer，浏览器无法直连。点击顶部「⟳ 数据更新」按钮：若检测到本地快照 reits_snapshot.js 将直接加载最新数据（无需刷新页面）；若未检测到，可下载自包含更新工具——Mac 用「更新数据.command」，Windows 用「更新数据.bat」（均内置 reits_update.py；浏览器无法指定下载路径，请把工具移到本 HTML 同文件夹后双击）——自动解出脚本、抓取两所最新数据、保留/补全项目分类、生成快照并回写本 HTML 内嵌数据；再点击「⟳ 数据更新」或「📥 导入快照文件」即可完成更新（手机端用导入功能）。
操作说明：
  • 重置视图（顶部按钮）：清除全部筛选条件、恢复默认排序（更新日期降序）并显示全部项目；不会清除标记标签（重点跟踪状态保留）。
  • 清除全部（筛选面板右上角）：仅清除筛选条件，排序方式保持不变。
  • 交易所：顶部 Tab「全部 / 上交所 / 深交所」与左侧筛选面板的「交易所」多选联动，可一键查看单所或合并数据；每行有交易所徽章（上交所橙 / 深交所蓝）便于区分来源。
  • 项目类型 / 二级分类：表格新增两列：项目类型（经营权类 / 产权类）与二级分类（市政生态、交通设施、能源；产业园、租赁住房、物流仓储、消费、数据中心、办公、综合业态、文旅类）。「二级分类」筛选选项随「项目类型」选择联动（选经营权类只显示其 3 个子类，选产权类只显示其 8 个子类）。点击「项目类型」或「二级分类」单元格即可手动修改分类（选择后保存到浏览器本地，带 ✎ 标记；筛选与图表跟随手动分类）。
  • 筛选：左侧面板支持关键字搜索、交易所、项目类型、二级分类、标记状态、项目状态、原始权益人、计划管理人、承销商多选（下拉仅列出实际存在的选项），以及拟发行金额区间、受理/更新日期区间；多条件可叠加。
  • 排序：点击表头（债券名称、原始权益人、金额、日期等）即可切换升/降序，金额与日期默认降序。
  • 标记：点击行尾「标记」按钮，或在任意数据行上右键，可打上「重点关注 / 已审核 / 待跟进」或自定义标签；标记随浏览器本地保存（localStorage 双备份），刷新不丢失。
  • 图表：「计划管理人 TOP10」支持按金额/单量切换，「近12个月受理趋势」按受理日期统计、支持金额/单量切换。
  • 导出 CSV：顶部「导出 CSV」按钮将当前筛选结果导出为表格文件（含标记列）。
  • 数据更新：点击顶部「⟳ 数据更新」：若检测到本地快照 reits_snapshot.js 会直接加载最新数据；若未检测到，Mac 下载 更新数据.command、Windows 下载 更新数据.bat（均自包含，内置 py 脚本），移到本 HTML 同文件夹双击，抓取两所最新数据后，再点一次「⟳ 数据更新」或刷新本页（详见上方「数据更新」说明）。

⟳ 数据更新工具

本页单文件即开即用（数据已内嵌，分享给别人打开即可查看）。浏览器安全策略无法直连交易所接口（需校验 Referer），更新数据有两条路：① 桌面端只需下载 1 个自包含工具——Mac 下载「更新数据.command」、Windows 下载「更新数据.bat」（均内置抓取脚本，无需再下载 py）。因浏览器无法指定下载路径，请把工具移到本 HTML 同文件夹后双击，它会自动检测位置、抓取最新数据并回写本 HTML；② 直接导入快照文件（把 reits_snapshot.js 通过微信/邮件发到当前设备，点「📥 导入快照文件」选择它即可，手机也适用）。「下载 reits_snapshot.js」可导出当前数据快照。
  1. 查看数据：把本 HTML 直接发给任何人，打开即看到最新项目数据（无需其他文件）
  2. 桌面端更新：Mac 下载 更新数据.command ／ Windows 下载 更新数据.bat（任选 1 个，均自包含）→ 移到本 HTML 同文件夹 → 双击（自动解出脚本、抓取最新数据、生成快照并回写本 HTML 内嵌数据）
  3. 手机/免脚本更新：拿到 reits_snapshot.js 文件后，点「📥 导入快照文件」选择它，立即加载最新数据
  4. 导出快照：点「下载 reits_snapshot.js」把当前数据存为快照文件，可发给其他设备/看板使用
